# 维护与一次性修复

这里存放需要人工审查的迁移、诊断或一次性维护脚本。它们不是 Harbor task 的运行时依赖，也不会被复制到 `output/task-NNNN/`。

通用生产逻辑必须修改 `pipeline/` 并提交版本控制；不要让强模型或弱模型在生产运行中直接改写产线代码。某个 task 生成的源码、参考实现和测试只属于该 task 的 staging，QA 通过并发布后可按 `docs/ARTIFACT_LIFECYCLE.md` 清理。

任何一次性脚本都应说明：适用范围、输入/输出、是否可重复运行，以及验证命令。不得在此处保存 API key、模型响应或未脱敏日志。
